Проект автоматизированного UI тестирования веб-приложения Stellar Burgers. Включает полное покрытие тестов пользовательского интерфейса с использованием Selenium WebDriver, Page Object Pattern и интеграцией с API для подготовки тестовых данных

## 🛠 Технологии

| Технология | Версия | Назначение |
|------------|--------|------------|
| Java | 11 | Основной язык программирования |
| Maven | 3.9+ | Сборка проекта и управление зависимостями |
| Selenium WebDriver | 4.15.0 | Автоматизация взаимодействия с браузером |
| JUnit | 4.13.2 | Фреймворк для модульного тестирования |
| Allure | 2.24.0 | Построение отчетов о тестировании |
| REST Assured | 5.3.0 | Тестирование REST API для подготовки данных |
| JavaFaker | 1.0.2 | Генерация тестовых данных пользователей |

## 🚀 Быстрый старт

### Предварительные требования

- Установленная **Java JDK 11** или выше

- **Google Chrome** версии 141 или выше

## ▶️ Запуск тестов

### Основные команды

```bash
# Запуск всех тестов в Chrome (по умолчанию)
mvn clean test
# Запуск в Яндекс Браузере
mvn clean test -Pyandex
# Запуск конкретного тестового класса
mvn test -Dtest=RegisterTest
mvn test -Dtest=LoginTest
mvn test -Dtest=ConstructorTest
mvn test -Dtest=LogoutTest
mvn test -Dtest=NavigationTest
```

### Параметризованный запуск

```bash
# Запуск только тестов авторизации и регистрации
mvn test -Dtest="*Test" -Dtest.excludes="*ConstructorTest,*NavigationTest"
# Запуск с детальным логированием
mvn test -Dtest=LoginTest -X
```

```bash

mvn allure:serve
```

### Структура отчета

- **Обзор** - общая статистика 17 тестов
- **Графики** - диаграммы успешных тестов
- **Сьюиты** - группировка по тестовым классам
- **Шаги** - детальная информация о каждом шаге UI теста
- **Скриншоты** - автоматические скриншоты при ошибках

## 📝 Примеры использования

### Создание пользователя через API

```java
@Before
public void setUp() {
    super.setUp();
    // Создание тестового пользователя через API перед тестом
    String[] userData = ApiClient.createUserViaApi();
    testUserEmail = userData[0];
    testUserPassword = userData[1];
    testUserName = userData[2];
    testUserToken = userData[3];
}
```

### Page Object Pattern

```java
public class LoginPage extends BasePage {
    private final By emailField = By.xpath(".//input[@name='name']");
    private final By passwordField = By.xpath(".//input[@name='Пароль']");
    
    public void login(String email, String password) {
        setEmail(email);
        setPassword(password);
        clickLoginButton();
    }
}
```

### Тестирование навигации конструктора

```java
@Test
@DisplayName("Переход к разделу 'Булки'")
public void testBunSectionNavigation() {
    ConstructorPage constructorPage = new ConstructorPage(driver);
    constructorPage.clickBunSection();
    
    assertEquals("Должны быть активны 'Булки'", 
                 Constants.BUNS_SECTION_TEXT, 
                 constructorPage.getActiveSectionText());
    assertTrue("Должен произойти скролл", 
               constructorPage.isBunsSectionScrolledIntoView());
}
```
